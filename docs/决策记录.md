## 2026-11-17 · 迁移推进：merge_files + mkcpio OTA

**用户原话**：

> “那现在继续推进迁移？”

**已实现**：

- `wk image merge --output <file> --input <file> ...`：按顺序原样拼接，对应 `merge_files.py`。
- `wk image ota --ota-cfg <cfg> --image-cfg <json> [--input-dir] [--out-dir]`：
  - 第 3 行写回 `version = "<image.info.version>";`；
  - 生成 512B `ota_info.bin`（mkenvimage 等价）；
  - 解析 `[file]` 清单，生成 crc 格式 `ota.cpio`；
  - 把归档总大小回填到 `size = "..."` 字段。

**验证**：

- `zig build test` / `zig build` 通过（新增 merge、OTA 单测）。
- merge 实测：`1,2,3 + 4,5 + 6,7,8,9` → `1..9`。
- OTA 实测：合成配置 version `1.0.0` + image_cfg `9.9.9` → 输出 `version = "9.9.9";`，
  `ota.cpio` 1024 B，`cpio.exe -it` 列出 `ota_info.bin` / `app.bin`，`size` 回填 `1024`。
- backlog：P1-7（mkcpio OTA）、P2-1（merge_files）标记 ✅；审计表同步。

  `RAM_BASE + RAM_SIZE - HEAP_SIZE - TEXT_SIZE` 计算，显式模式取 TEXT_BASE；
  实测 `text=0x400ef000`、`load=0x400eef00`，4 个占位符均替换成功；backlog P2-2 标 ✅。

  `mcopy` 回读根文件与子目录文件均成功；FAT12/16 回归仍通过。`--fullpart` 与 `dirent_*` 留待后续。
