## 1. 项目速览

- 定位：Zig 0.17 复刻 Luban-Lite 主机侧（镜像格式/配置/打包/校验/烧写编排）。
- 参考：`G:\Code\C\luban-lite`；官方：`artinchip/luban-lite`。
- 产物：`wk` CLI（`zig build` → `zig-out\bin\wk.exe`）。
- 远程仓库：`origin` = <https://github.com/RemoteAll/WuKong-Lite.git>，默认分支 `main`。
- 接续指令：本机与各仓库模板已统一到 `2026.11.12.4`（拆分版 5 个文件 + 兼容索引；
  `_sync-user-instruction.ps1 -Check` 全盘一致）。

## 2. 常用命令

```powershell
zig build test                 # 回归（119 单测）
powershell -File tools\regression.ps1   # 一键回归（构建+单测+CLI 用例+对拍脚本）
zig build                      # 构建 wk.exe
.\zig-out\bin\wk.exe           # 命令帮助
wk image flashpack --payload-dir payload --out-dir flash
wk image rsakey -r key.pem [-a aes.key | -d des.key]   # 等价 encrypt_rsa_key.py
wk panic -l panic.log [-e app.elf]                     # 等价 panic_parse.py
wk sdk-update --root <SDK根目录> [--write]             # 等价 sdk_update.py
wk rtt2freertos <rt-thread_defconfig> [-o out]         # 等价 rtt2freertos.py
wk upg frame --cmd 0x31 --payload '{}'                 # upgcmd 帧协议（AA55/CRC16/55AA）
wk upg burn --image x.img                              # upg 请求载荷（与参考客户端一致）
tools\fetch-upgcmd-deps.ps1 -SdkRoot G:\Code\C\luban-lite
tools\build-zig-app.ps1 -App hello_uart
tools\sync-upstream.ps1 -Check
```

## 3. 当前状态（2026-11-17）

- 已验证：env/分区/FIT+ITS/AIC.FW/FAT(12/16)/sparse/cpio/AES-CBC/RSA/upgcmd 解析。
- Zig 裸机：`apps/hello_uart`（entry 0x41000000，UART0 输出，可 upgcmd write/exec）。
